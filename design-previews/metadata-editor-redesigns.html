Metadata editor — ten redesigns

A working layout study for the palette metadata editor. Every direction uses Lightroom’s useful structure: collapsible groups, group and field checkboxes, Check All / None / Filled below the scroll area, a light-grey bordered preset selector, a visible Add Field control, and a spacious action footer.

Metadata settings

One master template defines defaults for newly created assets; workflow presets decide which fields are applied or exported.

Master defaultsCreator, studio, rights holder, copyright, language, preferred credit line and custom fields. Creation time and file dates are generated from the asset and file, not typed into this template.
On createApply the master defaults, then choose an optional creation preset by asset type. The creation form shows the values for review before saving.
On exportChoose an export preset that includes only the fields appropriate for the recipient and format. Preview exactly what will leave the app.
PresetsCreate, duplicate, rename and remove presets. Each stores field inclusion, values where appropriate, custom field definitions and intended workflow.
