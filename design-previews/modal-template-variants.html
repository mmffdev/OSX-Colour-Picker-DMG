Common rules

Every example uses a four-column inner grid with 16-point gutters, Helvetica Neue, a four-point spacing rhythm, 13-point body copy, 11-point labels, 32-point controls, Rule separators and square modal edges. The 504-point standard modal is the reference size. Focus and the grid use the house orange only.

How to read this study

Try all three content modes and both appearances. The overlay is simulated; the buttons respond locally and do not change app data. Choose a layout direction here, then it can become the shared native modal primitive.
