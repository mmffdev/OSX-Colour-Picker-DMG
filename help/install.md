# Install MMFFDev Colour 3

Open the installer package and follow its steps. It offers two places for the app.

| Choice | Where the app goes | Password to install | Adding palettes to Adobe apps without a password |
|---|---|---|---|
| Install for all users of this computer | Applications | Yes, an administrator's | Allow the app once in System Settings ▸ General ▸ Login Items |
| Install for me only | Applications, inside your home folder | No | Enter an administrator's password once |

If the choice is not shown, press **Change Install Location…** on the destination step.

Everything else is the same either way: picking, palettes, exports and syncing all work from both places. The first time the app opens it walks you through what to allow; see "Add a palette to Photoshop, Illustrator or InDesign".
