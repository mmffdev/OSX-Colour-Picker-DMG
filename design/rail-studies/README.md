# Rail studies

Run `python3 -m http.server 8769 --bind 127.0.0.1` from this directory and open http://127.0.0.1:8769.

Ten treatments, each light/dark, with both rails. Use Compare for paired full-size appearances or the gallery for all twenty previews. On a narrow browser, scroll the preview horizontally to inspect Rail 2 without changing the app grid.

Folder expansion, palette selection, favourites, pick targets and search work with local sample data. States are shared between rails and theme previews. No app files or real catalogue data are changed.

Verified in browser: twenty gallery views; all ten layouts have 168px spectra, 108px rail headers, all 27 Library palettes and no overflowing palette rows. Cross-rail selection/target, 24-colour search result, and focus retention on tree expansion checked. Header metrics match AreaHeader and Design.swift.
