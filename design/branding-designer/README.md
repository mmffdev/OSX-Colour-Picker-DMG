# Designer ▸ Branding: the brand-pack builder, design study (2026-10-15)

Design only; nothing here is wired into the app. The live copies are on claude.ai:

- Design canvas, four artboards: https://claude.ai/artifact/M9ezmqz2k42TkThyJZ1RhX
- Capture document (research, competition, rationale, five open decisions): https://claude.ai/artifact/Dr3F3Gfbj7xHtaMg2gzxXP

This folder is the standalone copy for the repo. Open any file in a browser.

| File | What it is |
|---|---|
| `canvas/Main.html` | Colour page, the Brand system selected; Rail2 shows Document, Colour Systems, Why |
| `canvas/Typography.html` | Typography page, the hierarchy selected; Rail2 shows Typography, Why |
| `canvas/Brief.html` | Free-form brief page; Rail2 shows Document, Imagery, Why |
| `canvas/Decisions.html` | Decision-log page written from the Why records; Rail2 shows Output with pre-flight |
| `canvas/canvas.json` | The artboard index as published on the canvas |
| `capture.html` | The capture document |
| `img/` | Header, Rail1, Designer sub-menu and app footer cropped from Rick's screenshot of build a472da6+; the artboards reuse them so nothing in the fixed layout is redrawn |

Each artboard is 2866 × 1558, the logical size of the screenshot. The layout grammar of the pages follows Herman Miller's brand standards (number and title, paragraph, action, content block); the sample client, Fernhill, is invented.
