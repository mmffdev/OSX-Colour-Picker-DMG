# Viewport colour picker studies

Five interactive visual studies for a colour picker in the existing Viewport-Page. They are review artifacts, not native implementation; choosing a swatch changes this prototype only. Every direction uses small grid thumbnails, groups chromatic hues, and separates warm, cold and natural greys. Use the numbered controls to compare structures and the Light/Dark buttons to preview themes.

Study 2, Tonal columns, is the selected direction under review. It retains the original pale-to-deep tonal rows and adds four high-chroma rows inspired by the bright reference, with Yellow, Magenta and Rose columns. The three grey families remain separate.

The app header, Actionbar, Rail 1 and Rail 2 remain visible to establish the placement. The real Colorgain catalogue, workspace and preferences are untouched by this page. Generated swatches are illustrative sRGB values; the eventual native picker should use the chosen layout with the app's colour-management model.
