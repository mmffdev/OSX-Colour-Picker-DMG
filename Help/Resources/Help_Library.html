Library

Your Library connects catalogues, favourites, project folders and your own palettes. The header collapses the whole panel. Drag its six-dot handle to move it between rails. The outlined hexagon opens this guide; each section’s hexagon opens its place in the same guide.

Catalogues

A catalogue is a separate working library with its own schema, project folders and assets. Click a catalogue name to open it. The selected row identifies the active catalogue. Use + to open or add a catalogue through the existing catalogue journey.

Remove, Backup and Export

  • Remove opens a review wizard. Inspect the verified and last-known inventory, ownership and schema before choosing what happens to the files. Detach leaves files on disk; transfer preserves the source; archiving creates a checked share before detaching. Moving owned files to the Bin is a separate reviewed choice. Unknown artwork and shared external originals are retained.
  • Backup creates a uniquely named, verified .colshr archive in your workspace’s Backups/Catalogues folder. The catalogue remains registered. Use Show In Finder after completion to find the archive.
  • Export asks where to save a verified .colshr archive. Use a new filename. It leaves the catalogue and its original files in place.

Backups and exports include the catalogue’s inventoried files and individual linked ASE files. Shared global assets are not bundled by these row actions; external ICC references remain links unless embedded in a proof. Monitored ASE folders need conversion to individual links before archiving. Missing dependencies block an incomplete archive and lead to recovery.

When files go missing

Colorgain keeps the catalogue reference and your current session. A grouped recovery message names the affected files. Retry after reconnecting storage; Locate or restore a matching file; grant folder access when needed; or detach the registration while leaving disk files in place. A folder containing a different catalogue identity cannot silently replace the expected one.

Finder changes can produce a reconciliation proposal. Review it before accepting the changed disk structure. The workspace manifest (colorgain.coldata) stores the catalogue list and portable app settings; it is different from an individual catalogue’s .colcat index. Use File → Open Workspace… to open another workspace.

Favs

Favs is a shortcut list for palettes you have starred. Click a favourite to open the palette; remove its star to remove the shortcut. This does not delete the palette. A favourite colour chip controls its saved row background, with readable text chosen against it.

Folders

Folders follows the active catalogue’s actual schema: collections, projects and their asset buckets. Expand a branch to navigate. Select a palette to open it in the centre canvas. Folders has no rating or flag filter bar, so My Palette’s filters do not hide its contents.

Drag a palette from the Library, canvas or carousel to a compatible project or palette bucket. A valid destination gains a yellow outline. The drop creates an independent project copy and retains the source palette. Branches with several possible destinations must be expanded until one target is clear.

My Palette’s

My Palette’s lists unassigned app-owned palettes and retained claimed copies. Project-owned palettes remain in their Folders buckets. When the list is genuinely empty, it says “You have no palettes.” and hides its filter controls.

When palettes exist, use Rating, Flag and Order to narrow or arrange this list. If the filters exclude every palette, the controls remain available and the message says “No palettes match your filters.” Clear or change the filters to see them again.

Click a palette to view its colours. Double-click a name to rename it. The target control sends new picker samples to that palette; the star adds it to Favs. Rating and flag values belong to the palette and travel with its file.
