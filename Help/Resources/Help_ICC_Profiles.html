ICC Profiles

Browse ColorSync system profiles and profiles you have linked with Add File or Add Folder. Use As Target applies a supported colour profile to the workspace target. Linked files remain in their original location. Missing or changed profiles retain a warning and a Locate action; Remove Link does not delete their files.

Panel Controls

Use the disclosure arrow to collapse or expand the panel. Where available, drag the six-dot handle to move the panel between rails. The outlined question-mark hexagon opens this guide without changing your working selection.
