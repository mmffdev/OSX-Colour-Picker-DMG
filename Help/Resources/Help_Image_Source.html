Image Source

The From panel belongs to image intake. Choose the source image and review the colours extracted from it before adding them to your library. The source file remains separate from the destination catalogue. Image sampling is not a measured print proof.

Panel Controls

Use the disclosure arrow to collapse or expand the panel. Where available, drag the six-dot handle to move the panel between rails. The outlined question-mark hexagon opens this guide without changing your working selection.

Read the Library guide for catalogue navigation, file recovery, backup and export.
