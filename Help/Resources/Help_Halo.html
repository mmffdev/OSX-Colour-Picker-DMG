Halo

Halo is Colorgain’s contextual action menu. It gathers the actions available for the palette, colour or selection you opened it from. It does not calculate a proofing verdict. The selected object and the words shown in the menu determine what an action will affect.

An Action Menu For The Current Object

A palette Halo can offer viewing, rename, favourite, picker targeting, duplication, destination, copying, export and deletion actions. A colour Halo offers actions appropriate to that colour and its context. A multi-palette selection can offer a different set again. An action absent from one context is not necessarily a missing feature in another.

The concentric action mark is different from a passing tick, warning triangle, rating star or flag. Read the Palette Page review controls if you are looking for those markers.

Open The Right Halo

Use the Halo mark on a palette card or the contextual action offered for an individual colour. Before choosing an action, read the object name and the action label. Opening a menu does not itself copy, rename, move or delete the object.

A larger palette viewer and the Halo are different surfaces. View opens a visual inspection experience; Open Swatches opens the palette’s entries on the normal page. Close a viewer to return to the page without confusing it with a destination change.

Navigate And Close

Move the pointer over an action and click to choose it. Where the Halo opens as a dial, scrolling turns the active ring. An action with further choices opens another level. Read the current level before confirming.

  • Arrow keys move among actions on the active ring.
  • Return or Space chooses the focused action when it is available.
  • Home and End move to the first or last available action in a normal action ring.
  • Tab moves keyboard focus between the dial and its close control.
  • Escape backs out of editing or confirmation, then steps back through outer levels, and closes the first level.
  • Click outside dismisses the Halo. A centred Halo can consume that click so it does not also activate an unrelated control behind it.

When an action opens a name field, enter the text and use the field’s stated completion control. Do not assume the arrow keys still navigate the ring while editing text. Controls can differ between configured menu presentations; follow the visible labels and confirmation instructions.

The precise list follows the selected object and its ownership. Do not assume a similarly named action in another context affects the same scope. For colour fidelity, return to Preset, Target and Tolerance.

Colour Actions

A colour Halo acts on the selected colour, not the complete palette, unless the action explicitly says otherwise. Copying a formatted value is different from editing its master definition. Keep the target and encoding with any copied numbers, especially CMYK, video and scene-linear values.

If the action opens another tool, viewer or delivery flow, read that surface’s selected colour and scope. Closing the Halo after choosing an action does not mean that every subsequent dialog has been accepted.

Choose A Destination

Copy or destination actions can open a ring of choices or a larger destination gallery. Navigate the catalogue’s actual hierarchy. Its names and levels are configurable; the receiving owning location matters more than any generic example name.

Check the source palette, selected destination and final action label before committing. A copy retains the source and creates independent destination content. A move changes where the selected content belongs. Do not infer which operation will occur from the visual shape of the chooser.

Cancel or close the chooser if the destination is wrong. Do not select an arbitrary branch just to dismiss it. See Library and Folders for ownership and navigation.

Confirm Deliberately

Actions that need confirmation display a specific confirmation control. Follow the visible slide or keyboard instructions and complete the required travel. In a dial confirmation, the indicated arrow keys adjust progress; Return confirms only after completion. Escape backs out.

A confirmation applies to the named action and object. A menu opening, highlight or partial slide is not approval of a different operation. Before deleting, distinguish removing a shortcut, removing a saved preset and deleting palette content.

Presentation And Related Help

Halo settings control its presentation and interaction preferences. Changing presentation does not change the target colour profile, the palette’s owner or its colour-difference tolerance. Menu actions can be unavailable when their context does not support them.
