# Getting Started

Colorgain brings your colours, palettes and print predictions into one workspace.

## Pick A Colour

Use the eyedropper in the header to pick a screen colour. Use Rectangle Picker to sample colours from an area. New samples are added to the current picker target.

## View And Copy

Hover over a swatch or palette to open its action halo. View opens a larger preview. Copy uses the format selected in the header. A palette also offers Open Swatches.

## Check A Palette For Print

Open PrePress, then Will It Print? Select a palette and printing condition to see its predicted colour differences. Save a print profile to reuse those settings. These are profile predictions, not measured proofs.

## Share Colours

Use QR from a swatch or palette halo. Import accepts a QR from an image, the clipboard or an allowed camera. Review the colours before importing them.
