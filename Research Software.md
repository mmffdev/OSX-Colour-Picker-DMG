# Design Applications & File Types Reference

---

## 2D RASTER (Photo & Pixel Editing)

| Application Name | File Type | Description | Format |
| :--- | :--- | :--- | :--- |
| Adobe Photoshop | `.PSD` | Layered raster image file; retains editable layers, masks, and effects. | Native, layered |
| Adobe Photoshop | `.TIFF` | High-quality raster image format; supports layers and lossless compression. | Flat/layered, lossless |
| GIMP | `.XCF` | Native layered raster file; stores channels, paths, and editable layers. | Native, layered |
| Corel PaintShop Pro | `.PSPIMAGE` | Layered raster file; retains adjustment layers and vector objects. | Native, layered |

---

## 2D VECTOR (Logos, Icons & Illustration)

| Application Name | File Type | Description | Format |
| :--- | :--- | :--- | :--- |
| Adobe Illustrator | `.AI` | Vector graphics file; stores editable paths, shapes, and artboards. | Native, vector |
| Adobe Illustrator | `.EPS` | Encapsulated PostScript; vector format widely used for print and cross-app exchange. | Vector, print-ready |
| Affinity Designer | `.afdesign` | Native vector document; holds editable layers, artboards, and styles. | Native, vector |
| CorelDRAW | `.CDR` | Native vector document; stores editable curves, fills, and page layouts. | Native, vector |
| Inkscape | `.SVG` | Scalable Vector Graphics; open XML-based vector format for web and print. | Open standard, vector |

| Application Name | File Type | Description | Format |
| :--- | :--- | :--- | :--- |
| Adobe InDesign | `.INDD` | Page layout document; contains master pages, text frames, and linked assets. | Native, layout |
| Affinity Publisher | `.afpub` | Native layout document; stores spreads, master pages, and linked graphics. | Native, layout |
| QuarkXPress | `.QXP` | Page layout file; stores text, images, and print-ready page compositions. | Native, layout |

## 3D MODELING & ANIMATION

| Application Name | File Type | Description | Format |
| :--- | :--- | :--- | :--- |
| Autodesk Maya | `.ma` / `.mb` | Maya scene file (ASCII `.ma` or binary `.mb`); stores geometry, rigs, and animation. | Native, scene |
| Autodesk 3ds Max | `.max` | Native scene file; stores models, materials, lights, and animation data. | Native, scene |
| Blender | `.blend` | Native project file; stores meshes, modifiers, shaders, and animation. | Native, scene |
| Cinema 4D | `.c4d` | Native scene file; stores motion graphics, MoGraph data, and simulation. | Native, scene |

## 3D CAD (Parametric & Engineering)

| Application Name | File Type | Description | Format |
| :--- | :--- | :--- | :--- |
| SolidWorks | `.SLDPRT` / `.SLDASM` | Part (`.SLDPRT`) and assembly (`.SLDASM`) files; store parametric features and mates. | Native, CAD |
| Autodesk Fusion 360 | `.f3d` | Parametric design file; stores sketches, features, and timeline history. | Native, CAD |
| AutoCAD | `.DWG` / `.DXF` | CAD drawing (`.DWG`) and interchange (`.DXF`) formats for 2D/3D technical drawings. | Native/exchange, CAD |

## 3D EXCHANGE & UNIVERSAL FORMATS

| Application Name | File Type | Description | Format |
| :--- | :--- | :--- | :--- |
| (Cross-application) | `.FBX` | Universal 3D exchange format; carries geometry, materials, rigs, and animation. | Exchange, 3D |
| (Cross-application) | `.OBJ` | Universal 3D mesh format; stores geometry and UVs, widely supported. | Exchange, 3D |
| (Cross-application) | `.STL` | Stereolithography mesh format; used for 3D printing and CAD exchange. | Exchange, 3D print |
| (Cross-application) | `.GLTF` / `.GLB` | Web-friendly 3D format; stores geometry, materials, and animation for real-time. | Exchange, web 3D |

## COLOUR SWATCH FILE TYPES

| Application Name | File Type | Description | Format |
| :--- | :--- | :--- | :--- |
| Adobe (all apps) | `.ASE` | Adobe Swatch Exchange; stores solid colour swatches for cross-app sharing. | Swatch exchange |
| Adobe (all apps) | `.ACB` / `.ACBL` | Adobe Color Book; stores standardized colour libraries (e.g., PANTONE). | Swatch library |
| Adobe Photoshop | `.ACO` | Photoshop colour swatch file; stores palettes for use within Photoshop. | Swatch palette |
| GIMP / Inkscape | `.GPL` | GIMP Palette; plain-text colour palette for open-source apps. | Swatch palette |
