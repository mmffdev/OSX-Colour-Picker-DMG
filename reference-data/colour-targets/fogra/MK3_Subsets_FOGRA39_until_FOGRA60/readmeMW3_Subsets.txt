Fogra, www.Fogra.orgJanuary, 2022FOGRA39 to FOGRA60These characterization data contain the 72 Ugra/Fogra MediaWedge V.3 tone value patches to be a valid subset of ISO 12642-1, ISO 12647-2 and ISO 12642-3.
It is expected that all evaluation programs handle the correct correspondence between the CMYK tint and CIELAB values. FOGRA55 is a 7C (CMYKOGV) colourspace, hence the 102 patches of the Fogra MediaWedge Multicolor V1 are taken.FOGRA58 is an RGB based colourspace, hence the subset is done for the Fogra MediaWedge Textile V1 with 128 RGB tone values.
