Colour is the product.
Images are one way in.

Colorgain is not trying to replace Lightroom or Photoshop. Its purpose is to help people understand, develop and deliver colour with confidence across digital and physical work.

Image cataloguing and development extend the colour toolkit: they help people organise visual references, extract colours and build dependable colour outputs. This brief combines that product direction with the engine scan and RAW research.

01 / Product idea

A colour system with many ways in

Colorgain helps artists, creatives, print professionals, photographers and scientists develop colour outputs they can trust for print, products, screens and other physical or digital media. Its distinctive centre is colour: how colours are captured, related, transformed, evaluated and delivered.

North star
Help people move from colour source to colour decision to dependable output—with the reasoning, measurements and provenance intact.

People can begin with colours they design themselves, palettes and swatches they already have, or colours extracted from digital images. The image library is a gateway into that colour work, not an attempt to reproduce every feature of Lightroom or Photoshop.

Product role

Organise the visual work

Collect images in useful groups and find them again through location, filters, tags and metadata. Copy into a managed catalogue or add by link, keeping source ownership clear.

Colour role

Turn sources into colour

Extract colour from an image, a selected region, a designed palette or a swatch. Develop and assess those colours for their intended use, then carry the result into reusable palettes, proofs and handovers.

Image tools should serve this journey: enough reading, editing and development to make extraction meaningful and repeatable, while specialist photo-editing workflows remain in the tools built for them. Keep originals unchanged; store development settings, crops, masks, versions and extracted palettes as linked work. Removing an image from a catalogue remains distinct from deleting its source.

Designed colour sources

Start from a seed, an authored palette, a swatch collection or an existing Colorgain project. Preserve colour values, roles and provenance.

Image sources

Import or link photographs, organise them by location and metadata, and extract colours from the whole image or a chosen region.

Develop and validate

Use nodes and colour tools to shape relationships, test print or product constraints, and make intended-use decisions visible.

Deliver with confidence

Produce appropriate colour values and supporting evidence for screens, print, manufactured objects and scientific workflows.

02 / Architecture

Native shell, portable graph, replaceable image backends

Swift is well suited to the Mac application and can coordinate work through Apple frameworks and native libraries. A Rust core is a strong proposal for graph evaluation and colour rules because it can run without the UI and be reused by a future Windows application. Rust is for portability and a clean engine boundary, not because Swift cannot be fast.

Working design; engine choices remain candidates until benchmarked and distribution-reviewed.

Pass full-precision colour records and explicit image references across the boundary. Do not pass AppKit objects or serialise megapixels as JSON. Large buffers need clear ownership and lifetime rules. A portable graph does not mean every platform renders a RAW identically.

03 / Options scan

Use mature engines where they are strongest

No single language or open library supplies a complete Lightroom/Resolve-class stack. The mature options for the named operations are largely C and C++. Rust can orchestrate them through narrow C interfaces without rewriting them.

04 / Image pipeline

Keep the source, render a view, extract a recipe

RAW has no single definitive palette. White balance, exposure and development change its rendered colours. Record those settings with the extraction. Keep an approved rendered snapshot when reproducibility matters; retain the original if a future decoder changes.

DNG is a first-class source format
Apple ProRAW from supported iPhones is stored as .dng. ProRAW is a linearized, computationally fused DNG, not the same kind of mosaic sensor RAW as many camera files; its embedded tags and previews carry important rendering intent. Read DNG at import and preserve the original bytes and metadata. Apple Support: ProRAW uses DNG · Apple: ProRAW structure and processing.

Read and develop

Use Image I/O and Core Image as the native Mac path, test against real iPhone ProRAW samples, and honor embedded previews and DNG rendering metadata. Detect linear, mosaic and other DNG variants instead of assuming every .dng has the same pixel model.

Convert with intent

Offer an explicit, non-destructive “Convert to DNG” job for supported proprietary RAW sources. Keep the source, write to a chosen destination, report metadata or maker-note limitations, and distinguish mosaic-preserving conversion from linear (demosaiced) DNG. Mosaic-to-linear is one-way; never silently convert ProRAW to another DNG flavor.

Conversion is a compatibility and archive option, not a prerequisite for catalogue import or palette extraction. The DNG specification is public and grants a royalty-free implementation patent licence, while Adobe’s DNG SDK is a separate dependency whose exact current distribution terms still need review. The free Adobe DNG Converter is a useful workflow reference, not an assumed embeddable component. Adobe DNG Converter and conversion options · DNG specification and SDK.

Image wire

References a developed image or versioned development recipe.

Mask wire

Defines a region or weighted selection for extraction and later image operations.

Palette wire

Carries identities, roles, proportions, source lineage and status.

Selection wire

Targets stable entries, optionally with soft weights, rather than fragile list positions.

Candidate nodes include dominant colours, small accents, region selection, exclude, sample path, collection palette, image comparison, brand match and later palette remapping. Extracted colours describe rendered appearance; they are not automatically measurements of photographed materials.

05 / Responsiveness

Background work yields to the person using the app

Prepare previews and thumbnails in the background while reducing or pausing that work when foreground editing needs the machine. Threaded libraries help within an operation; they do not coordinate the whole application. One app-level scheduler must prevent nested thread pools from overwhelming CPU, GPU or memory.

  • Coalesce rapid changes; do not queue every intermediate preview.
  • Recompute only invalidated descendants and share upstream cache across branches.
  • Bound global CPU/GPU work, accounting for backends that create their own threads.
  • Keep separate budgets for interactive RAW work and background catalogue jobs.
  • Show import/export progress; keep routine thumbnail preparation quiet.

Measure responsiveness while import, thumbnails, RAW editing and graph changes happen together, not only on an idle machine.

06 / Apple RAW

RAW 9 is a meaningful Mac advantage—with conditions

Apple’s WWDC 2026 session describes RAW 9 as a Core Image pipeline using a tiled Core ML model for demosaic and denoise, accelerated by Apple Neural Engine. Apple reports sharper detail and better colour definition over RAW 8. The session says it is coming with macOS 27 and related platform releases, supporting hundreds of camera models. Treat it as a capability to detect at runtime, not a format guarantee. Apple WWDC 2026: Enhance RAW image processing with Core Image.

Opt in per image

RAW 9 is not enabled by default. Check supported decoder versions and select version 9 only when available; otherwise use a supported fallback. Decoder versions.

Expose supported controls

CIRAWFilter provides calibrated properties including exposure, luminance noise reduction, sharpness and contrast. Query capabilities for each image before enabling controls. CIRAWFilter.

Budget first-render cost

RAW 9’s first render costs more. Apple recommends scaleFactor for smaller previews, a reusable CIContext with intermediate caching, and Metal-backed rendering for interactive work.

Record pixel provenance

Save decoder version, settings, source fingerprint and output colour interpretation. Preserve approved renders when later OS versions change RAW development.

Use RAW 9 on supported Mac images, with a clear fallback and versioned recipe. A Windows backend may render differently. Portable recipe does not mean identical pixels; exact appearance needs compatible dependencies or a frozen render.

07 / Validation

Prove one vertical slice, then choose by evidence

  1. Image identityCopy/link sample RAW, JPEG and TIFF. Preserve metadata, detect missing links and make previews without blocking UI.
  2. RAW developmentUse CIRAWFilter on Mac, detect decoder versions, expose key controls and compare RAW 9 with fallback on supported files.
  3. ExtractionReturn full colour records, proportions, region, settings and stable lineage—not hex-only samples.
  4. Graph bridgeSwift submits an operation to Rust; Rust evaluates Seed/Catalogue → Ramp → Select → Adjust → Check and returns results plus Why trace. Run the graph in a command-line test.
  5. Engine benchmarkCompare OCIO/OIIO and libvips on curves, conversion, preview speed, cancellation, HDR/alpha, memory and Mac/Windows packaging.
  6. Scheduler stressRun import, thumbnails, RAW edit and graph changes together. Measure interaction latency, memory peaks and cancellation.
  7. Distribution reviewPin versions; audit dependency licences, binary size, notarisation and App Store sandbox compatibility.
Success demonstration
Change a brand seed; supporting colours regenerate, an approved anchor stays fixed, a failed contrast pair is identified and Why explains each change. Repeat using a palette extracted from RAW.

First release: catalogue, image source, sufficient development for extraction, extraction, graph, checks, Why and output. Add collection analysis, advanced masks, palette remapping and broader photo editing after this proves useful.
