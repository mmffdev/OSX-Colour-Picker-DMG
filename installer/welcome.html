MMFFDev Colour 3 picks, keeps and shares colours. It can live in one of two places. The next step lets you choose; press Change Install Location… if the choice is not shown straight away.

Install for all users of this computer

The app goes in the Applications folder. Needs an administrator's name and password now.

  • Everyone with an account on this Mac can use it.
  • Adding palettes to Photoshop, Illustrator and InDesign without a password each time is done by a small helper that you allow once in System Settings ▸ General ▸ Login Items.

Install for me only

The app goes in the Applications folder inside your home folder. No password is needed to install.

  • Only your account sees it.
  • Adding palettes to Photoshop, Illustrator and InDesign without a password each time is done by giving your account leave to add files to those apps' library folders. An administrator's password is asked for once.

When the app first opens it walks you through these choices. Everything else is the same either way: picking, palettes, exports and syncing all work from both places.
