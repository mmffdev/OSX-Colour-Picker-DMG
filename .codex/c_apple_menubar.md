# Apple Menubar — App Store

Built in `codex/apple-menubar`, from the current uncommitted app baseline. `AppleMenubar.swift` is guarded by `APPSTORE`; the direct-download build has no status item or settings entry.

A single movable status item groups recent swatches, the shared `Prefs.copyFormat` selector and the Colorgain icon. The icon menu reuses `LibraryController` Picker and Rectangle Picker. Ten slots are shown initially; Settings → Apple Menubar → 01 Settings can hide them, choose 1–20, and mute menubar sounds. Empty slots remain disabled until real samples arrive.

`ColourCopies` retains twenty entries in portable app data; the footer displays its latest ten. Rectangle samples entered through the menubar are remembered without changing the clipboard. Clicking a swatch uses the selected format and preserves source CMYK where available. Format changes notify both surfaces. Sound uses the existing Copy/Pick effects and respects Sounds master/event switches.

Will It Print result headers sort the entire palette, with stable ties and missing predictions last. `PrintBloomView` shares an Arrange Petals dropdown between inline and expanded views: palette order, fail/pass first, highest/lowest ΔE, and name. Sorting is stable, keeps missing predictions last for result ordering, and retains colour identity. Both palette dropdowns show spectrum strips below names in their values and menu rows. Dropdown click-away and Escape dismiss only the dropdown when it is inside the bloom. It uses a shared numeric ΔE radius scale and a dashed user-tolerance ring. Filled petals show the RGB master inside the tolerance radius and the existing print prediction outside it. Petals have colour-ID-based animated poses: a 0.62-second centre-out fan from twelve o’clock on first visible appearance, and a 0.38-second shortest-angle rotation for reordering. Interrupted motion resumes from the current pose; Reduce Motion settles immediately. The 15-physical-pixel outer ring is segmented per petal: green for ΔE at or below tolerance, red above, neutral without a prediction. These are profile predictions, never measurements or certification. Petal selection is linked to the table. The shared Swiss modal exposes palette, profile, rendering intent and tolerance controls.

New Palette creates an empty palette and saves it as the picker target without navigation. Its nonactivating naming bar offers Picker and Rectangle Picker beside the field. Return saves the name; Escape retains the saved default name. Rectangle capture appends to the target instead of creating another palette or reopening the workspace. The App Store app remains resident after closing its last window; Quit stays explicit.

Settings group spacing measures the wrapped description and snaps the next setting to the shared grid after one clear row. Library, General and Apple Menubar use this instead of fixed eight-row gaps. The expanded bloom fills the workspace between the app header and footer, with a far-right close arrow and Escape dismissal. It uses columns 1–3 for prediction controls, 4–8 for the bloom, and 9–12 for selected-colour outcome guidance. Outcome updates with petal selection, printing condition and tolerance; it distinguishes predicted pass/fail/unavailable from measured proof, prioritises replacing Generic CMYK with the actual production profile, and explains print alternatives and physical proofing without claiming automatic correction. All headings share the same strong guide and type style. The grid overlay can be shown inside the modal for verification.
