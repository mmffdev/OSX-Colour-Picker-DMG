# Type

Family: **Helvetica Neue**, on every Mac, nothing to license. Fallback Helvetica, then Arial. Never a monospace, not even for paths. Antialiased, negative tracking on anything large.

| Weight | Used for |
|---|---|
| UltraLight 100 | reserved |
| Thin 200 | display, numerals |
| Light 300 | titles, lead |
| Regular 400 | body, headline, caption |
| Medium 500 | heading, label, body strong, buttons |
| Bold 700 | the wordmark only |

## The eleven styles

| Style | Weight | Size / line | Tracking | Notes |
|---|---|---|---|---|
| Display | 200 | 88 / 0.92 | −4.5% | one per screen at most |
| Title | 300 | 48 / 1.0 | −3% | two-tone: first line ink, second line soft grey |
| Headline | 400 | 30 / 1.1 | −1.8% | |
| Heading | 500 | 17 / 1.25 | −0.5% | |
| Lead | 300 | 20 / 1.38 | −1% | at most 34em wide |
| Body | 400 | 13 / 1.55 | 0 | 60 characters wide; Body Strong is 500 |
| Caption | 400 | 11 / 1.45 | 0 | quiet grey; paths and metadata |
| Label | 500 | 11 / 1.2 | +6% | capitals, a 6pt dot in front: "● OPEN POSITIONS"; groups the rows under it |
| Section | 500 | 13 / 1.2 | +6% | capitals; the headings inside a page or an open row, About, Directory, Contents, one step above the Labels that group rows beneath (Rick, 2026-10-08) |
| Numeral | 200 | 64 / 0.9 | −4% | tabular, right-aligned in its block |
| Action | 500 | 13 | 0 | buttons |

11 is the floor. In the app's `TextSize`, `caption` 11, `body` 13, `title` stays the page title; the wizard's larger sizes are its own.
