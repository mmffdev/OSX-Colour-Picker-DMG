# Colour

One light look. The wizard has no dark version; the app's dark theme is a later decision, not a given.

| Name | Hex | Use |
|---|---|---|
| Paper | #EEEDEA | the ground |

## Where colour goes

Colour is the user's work: swatches, tiles, the step cards, the 10-point band. The interface itself is ink on paper. The one accent is Orange #EC7A3C, for focus rings and the grid overlay only. The product's own colour, Blue Ribbon #2456F5, is in `Brand.swift` and marks the footer's current colour and the halo's wedge; it is not a UI accent.
